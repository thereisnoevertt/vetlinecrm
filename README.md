# Ветлайн ВК — информационная система взаимодействия с клиентами

CRM-система для предприятия по продаже ветеринарного оборудования (ООО «Ветлайн»).
Переводит обработку клиентских заявок из личных таблиц Excel в единую веб-систему:
приём заявок, управление их жизненным циклом, автоматические уведомления клиентов
через сообщество **ВКонтакте**, заказы поставщикам, аналитика и управленческий дашборд.

> Учебный проект (ВКР). Стек: **Java 17 · Spring Boot 3.2 · PostgreSQL 15 · Thymeleaf**.

---

## Возможности

- **Заявки** — приём с сайта через webhook (REST) и ручная регистрация менеджером;
  жизненный цикл из **11 статусов** с контролируемыми переходами (конечный автомат);
  карточка заявки с историей изменений; архивирование закрытых обращений.
- **Клиенты** — единая клиентская база с поиском (ФИО, телефон, организация, e-mail)
  и просмотром всех связанных с клиентом заявок.
- **Уведомления (VK-бот)** — автоматические сообщения клиенту при смене статуса заявки
  через VK Bot API (метод `messages.send`), с очередью и повторными попытками доставки.
- **Заказы поставщикам** — формирование заказов (в т.ч. иностранным) с привязкой
  к заявке-основанию; собственный жизненный цикл из 6 статусов.
- **Аналитика** — пять отчётов (О-01…О-05) с экспортом в **XLSX** (Apache POI)
  и **PDF** (OpenPDF, кириллица) и диаграммами Chart.js.
- **Дашборд директора** — 8 виджетов KPI с автообновлением и переключением периода.
- **Администрирование** — управление учётными записями, роли, сброс паролей.
- **Безопасность** — аутентификация по e-mail/паролю (BCrypt), ролевая модель
  (RBAC), журнал аудита, блокировка после неудачных попыток входа.

## Роли пользователей

| Роль | Возможности |
|------|-------------|
| `MANAGER` (Менеджер) | Регистрация и обработка заявок, заказы поставщикам, уведомления, отчёты по своим данным |
| `DIRECTOR` (Директор) | Просмотр всех заявок/заказов (только чтение), дашборд, все отчёты (вкл. О-05), план/факт |
| `ADMIN` (Администратор) | Управление пользователями и справочниками, сброс паролей, контроль инфраструктуры |

## Архитектура

Трёхзвенное веб-приложение: **браузер → сервер приложений (Spring Boot) → PostgreSQL**.
Дополнительно — интеграция с VK Bots Long Poll API и приём заявок с сайта по webhook.

```
src/main/java/ru/vetline/crm/
├── controller/   # HTTP-эндпоинты (заявки, клиенты, заказы, отчёты, дашборд, админка, webhook)
├── service/      # бизнес-логика (заявки, уведомления, отчёты, дашборд, PDF, аудит)
├── repository/   # Spring Data JPA репозитории
├── entity/       # JPA-сущности (12) и перечисления статусов
├── dto/          # объекты передачи данных
├── vk/           # клиент VK Bot API
└── config/       # конфигурация Spring Security и приложения
src/main/resources/
├── templates/    # Thymeleaf-шаблоны (tickets, clients, supplier_orders, reports, dashboard, admin)
├── static/       # CSS / JS
└── db/migration/ # Flyway-миграции V1…V4
```

## Быстрый старт

### Предварительные требования
- JDK 17+
- PostgreSQL 15+ (или Docker)
- Maven 3.9+ (или встроенный `./mvnw`)

### Вариант 1. Docker Compose (приложение + БД)

```bash
cp .env.example .env          # заполните секреты (см. таблицу ниже)
docker compose up -d --build
```

Приложение поднимется на http://localhost:8080, PostgreSQL — на `5432`.

### Вариант 2. Локальный запуск (Maven)

1. Создайте БД и пользователя в PostgreSQL:
   ```sql
   CREATE DATABASE vetline_crm;
   CREATE USER vetline WITH PASSWORD 'вашпароль';
   GRANT ALL PRIVILEGES ON DATABASE vetline_crm TO vetline;
   ```
2. Задайте переменные окружения (как минимум `VK_GROUP_TOKEN`, `VK_GROUP_ID`).
3. Запустите с профилем `local`:
   ```bash
   mvn spring-boot:run -Dspring-boot.run.profiles=local
   ```
   (в Windows можно использовать `run-local.bat`)

Схема БД создаётся автоматически миграциями Flyway при первом запуске.

## Конфигурация (переменные окружения)

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `DB_PASSWORD` | Пароль PostgreSQL | `vetline_secret_2025` |
| `VK_GROUP_TOKEN` | Access-токен сообщества ВКонтакте (права `messages`, `manage`) | — (обязательно) |
| `VK_GROUP_ID` | Числовой ID сообщества (без минуса) | — |
| `VK_API_VERSION` | Версия VK API | `5.199` |
| `WEBHOOK_SECRET_TOKEN` | Секрет для проверки webhook с сайта | `webhook_secret_2025` |
| `APP_BASE_URL` | Публичный URL системы | `http://localhost:8080` |

Токен сообщества ВКонтакте получают в настройках сообщества → «Работа с API».
Подробности по настройке бота — в [VK_BOT_DEPLOYMENT.md](VK_BOT_DEPLOYMENT.md),
развёртывание — в [DEPLOYMENT.md](DEPLOYMENT.md).

## Сборка

```bash
mvn clean package           # сборка исполняемого jar в target/
java -jar target/vetline-crm-1.0.0.jar --spring.profiles.active=prod
```

## Безопасность

- Секреты задаются **только через переменные окружения** (`.env` / окружение сервера)
  и не должны попадать в репозиторий.
- Файл `src/main/resources/application-local.yml` — локальная конфигурация разработчика,
  исключён из Git (`.gitignore`).
- Пароли пользователей хранятся в виде BCrypt-хэшей; доступ к API ограничен ролевой моделью.
