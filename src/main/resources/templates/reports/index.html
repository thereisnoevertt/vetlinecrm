Отчёты

Выберите тип отчёта, задайте период и выгрузите данные. Вы видите данные только по своим заявкам.

Параметры формирования

О-01 — По статусам заявок
Количество заявок в каждом статусе за период, доля от итога
Просмотр XLSX PDF
О-02 — По конверсиям
Доля выполненных заявок, активных и отменённых
Просмотр XLSX PDF
О-03 — По источникам обращений
Распределение заявок по каналам: сайт, телефон, мессенджер, e-mail и др.
Просмотр XLSX PDF
О-04 — По категориям товаров
Количество заявок в разрезе категорий ветеринарного оборудования
Просмотр XLSX PDF
О-05 — По эффективности менеджеров
Сводный отчёт по всем менеджерам — распределение статусов (только для директора)
Просмотр XLSX PDF
